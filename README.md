## 💻 Getting Started
1. Clone the repository.
```bash
git clone https://github.com/diro25/data-structures-practice.git
```
2. Navigate to the project folder.
```bash
cd data-structures-practice
```
3. Run any file.
```bash
python arrays/dynamic_array.py
```
